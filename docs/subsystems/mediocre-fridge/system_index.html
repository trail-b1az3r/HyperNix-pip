Public API

synthesize_judge_corpus(n, out_path, seed=0, good_ratio=0.5) -> Path

Write ``n`` judge examples to ``out_path`` as newline-separated text.

collect_responses_from(oven, prompts, max_new_tokens=32, temperature=0.7, label_rule=None) -> list[JudgeExample]

Sample responses from ``oven.complete(...)`` and wrap them as JudgeExamples.

write_examples(examples, out_path) -> Path

Serialize a sequence of JudgeExamples to a plain-text file.
